# Demo / Viva Checklist

The live demonstration should show:
1. Start FastAPI and open the UI.
2. Enter a monthly salary such as 40000 and show that the result uses exactly 40000 for financial calculations.
3. Change saving percentage and show available capacity changes.
4. Change Marriage, Car and Home timelines and show future costs/investments change.
5. Show ML salary prediction separately as a reference.
6. Show Agent natural-language planning.
7. Ask a RAG question that is answered from local documents.
8. Ask an unrelated RAG question and show the unavailable response.
9. Show the model comparison table with three models and no Random Forest.
10. Run `pytest -q` and show the passing test count.

The course PDF requires a demo video as a separate submission artifact; this repository includes the checklist and evidence, not a fabricated video file.
